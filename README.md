# heartdiseasepredict
 # Heart Disease Prediction App

This is a simple machine learning web app built with Streamlit to predict the presence of heart disease based on user inputs.

## Features
- Predicts heart disease based on medical inputs
- Interactive charts using Matplotlib and Pandas
- Built with Streamlit

## Installation

```bash
git clone https://github.com/Tar1000/heartdiseasepredict.git
cd heartdiseasepredict
python -m venv heartvenv
source venv/bin/activate  # On Windows: .\heartvenv\Scripts\activate
pip install -r requirements.txt
